</div>


## 📌 Sobre o curso

[Curso da **Udemy**](https://www.udemy.com/course/sql-para-analise-de-dados) que ensina a escrever queries em **SQL** para consultar dados de bancos de dados, com projetos que simulam situações reais do ambiente de negócios. A proposta é cobrir o que é preciso para se tornar um profissional de SQL.

**O que se aprende:**

- Sintaxe básica do SQL
- Filtragem de dados com `WHERE`
- Análise de dados agregados com `GROUP BY`
- Relacionamento entre tabelas com `JOIN`
- Queries avançadas com subqueries
- Limpeza e tratamento de dados
- Criação e manipulação de tabelas
- Aplicação do SQL na análise de dados de negócio


## 🎓 Sobre o repositório

Assisti a este curso como parte da formação do **Bootcamp AI-Driven Data Engineer** da AI/R Company. A formação exigiu o **curso completo**, e concluí **todas as seções**.
