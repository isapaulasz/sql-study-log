</div>


## 📌 Sobre o curso

[Curso da **Udemy**](https://www.udemy.com/course/banco-de-dados-da-modelagem-a-sql/) que ensina a criar e trabalhar com bancos de dados relacionais. O caminho parte de um modelo conceitual eficaz e eficiente, criado por meio de uma técnica bem definida, e passa pela normalização, com a apresentação das cinco formas normais, até chegar a um modelo lógico adequado. A criação do banco é concluída com o modelo físico, implementado em **PostgreSQL** via **SQL**.

**O que se aprende:**

- Modelagem conceitual de bancos de dados
- Normalização e as cinco formas normais
- Modelagem lógica para bancos relacionais
- Criação do modelo físico em PostgreSQL com SQL
